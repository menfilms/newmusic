# 🎵 MusicHub — Музыкальный сайт

Красивый музыкальный сайт с плеером и админ-панелью. Готов к деплою на **Netlify**.

## ✨ Возможности

- 🎧 **Аудиоплеер** — воспроизведение, перемотка, громкость, автопереход
- 📥 **Скачивание** — загрузка треков
- 🎛️ **Админ-панель** — добавление, редактирование, удаление треков
- 🔍 **Поиск и фильтрация** — по названию, артисту, альбому
- 📱 **Адаптивный дизайн** — работает на всех устройствах
- 💾 **localStorage** — данные хранятся в браузере

## 🚀 Деплой на Netlify

### Способ 1: Через GitHub (рекомендуется)

1. **Создайте репозиторий на GitHub:**
   ```bash
   git init
   git add .
   git commit -m "🎵 Initial commit - MusicHub"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
   git push -u origin main
   ```

2. **Подключите к Netlify:**
   - Зайдите на [app.netlify.com](https://app.netlify.com)
   - Нажмите **"Add new site"** → **"Import an existing project"**
   - Выберите **GitHub** → ваш репозиторий
   - Netlify автоматически определит настройки:
     - **Build command:** `npm run build`
     - **Publish directory:** `dist`
     - **Node version:** 20
   - Нажмите **"Deploy site"**

3. **Готово!** Сайт доступен по адресу `https://ваш-сайт.netlify.app`

### Способ 2: Netlify Drop (быстрый способ)

1. Установите зависимости и соберите проект:
   ```bash
   npm install
   npm run build
   ```

2. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop)

3. Перетащите папку **`dist`** в окно браузера

4. Сайт задеплоен мгновенно!

### Способ 3: Netlify CLI

```bash
# Установите CLI
npm install -g netlify-cli

# Войдите в аккаунт
netlify login

# Задеплойте
netlify deploy --prod --dir=dist
```

## 🔧 Настройка

### Смена пароля админки

Откройте `src/App.tsx` и найдите строку:
```typescript
const ADMIN_PASSWORD = 'admin123';
```
Замените `admin123` на свой пароль, затем пересоберите:
```bash
npm run build
```

### Добавление треков

1. Нажмите кнопку **«Админ»** в шапке сайта
2. Введите пароль (по умолчанию: `admin123`)
3. Заполните форму:
   - **Название** — название трека
   - **Артист** — имя исполнителя
   - **Альбом** — название альбома
   - **Тип** — сингл / альбом / релиз
   - **URL аудио** — прямая ссылка на MP3 файл
   - **URL обложки** — ссылка на изображение

### Где взять URL для аудио?

- **GitHub Releases** — загрузите MP3 в релиз репозитория
- **Cloudinary** — бесплатный хостинг медиа (до 25 ГБ)
- **Firebase Storage** — от Google, бесплатный тариф
- **BunnyCDN** — дешёвый CDN для аудио
- Любой хостинг с прямой ссылкой на файл

## ⚠️ Важно

- Данные хранятся в `localStorage` браузера посетителя
- При очистке кеша браузера данные удалятся
- Каждый посетитель видит свои добавленные треки
- Для общего хранилища нужен бэкенд (Supabase, Firebase и т.д.)

## 🐛 Решение проблем

### Ошибка сборки на Netlify

Если деплой не удался, проверьте:

1. **Node.js версия** — должен быть 20+
   - Убедитесь что `.nvmrc` содержит `20`
   - Или добавьте в `netlify.toml`:
     ```toml
     [build.environment]
       NODE_VERSION = "20"
     ```

2. **Зависимости** — все пакеты должны быть в `package.json`
   ```bash
   npm install
   npm run build
   ```

3. **Пути к файлам** — в `vite.config.ts` должно быть:
   ```typescript
   base: '/'
   ```

### Сайт не загружается после деплоя

1. Проверьте логи деплоя в Netlify Dashboard
2. Убедитесь что `dist/` содержит `index.html`
3. Проверьте что `_redirects` файл на месте
4. Очистите кеш браузера (Ctrl+Shift+R)

### Треки не воспроизводятся

- Убедитесь что URL аудиофайла доступен публично
- Проверьте CORS заголовки на сервере с аудио
- Используйте прямые ссылки на MP3 файлы
